# Dan’s Clams

Public website for **Dan’s Clams** (Cape Cod) — stuffed quahogs, lobster rolls, and fried clam bellies. Est. 2005.

Live site: https://platinum00001.github.io/dans-clams/

This is a static HTML/CSS site, hosted on GitHub Pages from the `main` branch root. It is **not** connected to dansclams.com (that domain is not pointed here).

## Brand assets

Logo files live in [`assets/brand/`](assets/brand/):

- SVG wordmarks (outlined type, for crisp text at any size) in `assets/brand/svg/`
- PNG exports, square social avatar (`avatar.png`, 1080×1080), and Facebook cover (`facebook-cover.png`, 1640×856) in `assets/brand/png/`

The mark keeps the existing navy line-drawn quahog and light-blue field, without the “PROVISIONS LM” line from the old sample logo.

## Placeholders

Several details were never published publicly. They are marked on the site and listed in [PLACEHOLDERS.md](PLACEHOLDERS.md). Please confirm them with Dan before treating the contact or “where to buy” sections as final.

## Local preview

Open `index.html` in a browser, or from this folder run:

```bash
python3 -m http.server 8080
```

## Game

[Catch the Clams](https://platinum00001.github.io/dans-clams/game.html) is a small HTML5 canvas game on this site (bucket, falling foil-wrapped clams, seagulls to dodge, local high score). No external game libraries.

## Menu note

Stuffed quahogs / stuffed clams are $10 each. Other prices are still placeholders.
